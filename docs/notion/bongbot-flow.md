# 붕봇 동작 순서 · 흐름 · 실행 순서

> 기준: 현재 코드(`ros2_ws/src/boong_robot`)와 `poses.yaml`. 좌표는 에뮬레이터용 예시값이고 **토요일(11/7)에 실제 좌표로 교체**한다.

## 1. 한눈에 보는 전체 흐름

```mermaid
flowchart LR
  A[웹앱 주문<br/>단팥/슈크림 · 수량] -->|서비스 /boong/submit_order| B[order_manager<br/>FIFO Queue]
  B -->|액션 goal /boong/make_bungeoppang| C[robot_action_server]
  C --> D[Bungeoppang<br/>동작 6개]
  D -->|movej / movel / 그리퍼| E[Doosan E0509<br/>실제 로봇 또는 에뮬레이터]
  C -.->|feedback: 단계| B
  B -.->|토픽 /boong/orders JSON| A
```

- 주문 = **action goal**, 붕어빵 완성 = **action result**, 단계 표시 = **action feedback**
- 한 번에 1건만 굽고, 나머지는 큐에서 선입선출로 대기
- 로봇 없이도 돌릴 수 있게 백엔드 2종: `dsr`(에뮬레이터/실제 로봇), `mock`(로그만)

## 2. 동작 순서 (붕어빵 1개) — 소스통 짜기 방식

반죽·앙금은 **다이소 소스통(스퀴즈 병)** 에 담아 두고, 로봇이 병을 집어 들어 **뒤집은 채 그리퍼로 눌러 짠다.** 점성이 다르면 **누르는 세기·시간**을 다르게 준다.

| # | 동작 | 함수 | 하는 일 | 웹 단계 | 우선순위 |
|---|---|---|---|---|---|
| 1 | 반죽 짜기 | `pour_batter()` | 병 집기 → 틀 위로 → **J6 180° 회전(주둥이 아래)** → 내려가 짜기 → 올라와 회전 복귀 → 병 제자리 | 반죽 붓는 중 | 🔴 |
| 2 | 앙금 짜기 | `add_filling(flavor)` | 팥/슈크림 병으로 같은 동작 (세기·시간만 다름) | 속 넣는 중 | 🟡 |
| 3 | 반죽 덮기 | `cover_filling()` | 반죽 병으로 앙금 위에 한 번 더 | 속 넣는 중 | 🟡 |
| 4 | 굽기 대기 | `wait_bake()` | 대기 (발표용 3초) | 굽는 중 | 🔴 |
| 5 | 틀 뒤집기 | `flip_mold()` | 툴을 눕혀 손잡이 잡기 → 120mm 들어올림 → **J6 180° 회전** → 내려놓기 → 대기 | 굽는 중 | 🔴 |
| 6 | 봉투에 담기 | `pick_to_bag()` | 붕어빵 집기 → 봉투 위로 → 그리퍼 열어 떨어뜨리기 | 포장 완료 | 🟡 |
| 끝 | 홈 복귀 | `home()` | action result 전송 | 픽업 대기 | 🔴 |

### 소스통 짜기 한 사이클 (`_dispense`)
1. 병을 **옆에서** 잡는다 (툴 수평, 병은 세워진 상태)
2. 150mm 들어올려 틀 위로 이동
3. **J6 180° 회전** → 병이 뒤집혀 주둥이가 아래를 향함 (6축 팔이라 별도 거꾸로 거치대 불필요)
4. 틀 쪽으로 내려가서, 그리퍼를 **잡고 있던 위치보다 더 조여** 병을 눌러 짠다
5. 올라와서 J6 −180° 복귀 → 병을 제자리에 내려놓고 놓기

### 재료별 누르기 (`poses.yaml` → `materials`)
| 재료 | 잡기 | 누르기 | 누르는 시간 | 비고 |
|---|---|---|---|---|
| 반죽 | 380 | 520 | 1.2초 | 묽음 |
| 팥앙금 | 380 | 620 | 2.0초 | 뻑뻑함 → 세게·오래 |
| 슈크림 | 380 | 560 | 1.6초 | 중간 |

숫자는 그리퍼 위치값(0 열림 ~ 700 닫힘)이며 **전부 예시. 토요일에 병을 실제로 눌러 보며 맞춘다.**

### 뒤집기에서 주의할 점
- 틀 손잡이를 **위에서 수직으로** 잡고 J6을 돌리면 틀이 화구 위에서 빙글 돌기만 한다.
- 그래서 손잡이는 **툴을 눕혀서(손잡이 방향을 보게)** 잡는다 → 손목 회전축 = 손잡이 축 → 진짜 뒤집힘.
- 좌표: `mold_handle: [470, 180, 110, -90, 90, 0]` (실제 경첩 방향에 맞는지는 모형 틀로 현장 확인)

## 3. 명령 단위 실행 순서 (단팥 1개 = 명령 91개)

백엔드 호출 기준 (movel 38 · 대기 23 · 그리퍼 12 · 누르기 위치 9 · J6 회전 7 · 홈 2).

1. **반죽 짜기** 홈 → 열기 → 병 옆으로 접근 → 병 위치로 → 잡기 → 들어올리기 → 틀 위 → J6 +180° → 내려가기 → 누르기(1.2초) → 올라오기 → J6 −180° → 병 자리 위 → 내려놓기 → 놓기 → 물러나기
2. **앙금 짜기** 같은 패턴, 병만 팥(`redbean_bottle`), 누르기 2.0초
3. **반죽 덮기** 1번과 같은 반죽 병
4. **굽기 대기** 3초
5. **틀 뒤집기** 열기 → 손잡이 옆 → 내려가기 → 잡기 → 들어올리기 → J6 180° → 돌아간 자세로 내려놓기 → 놓기 → 물러나기 → 3초 대기
6. **봉투 담기** 열기 → 붕어빵 위 → 내려가기 → 잡기 → 올라오기 → 봉투 위 → 놓기(떨어뜨리기) → 홈

## 4. 인터페이스

| 이름 | 종류 | 내용 |
|---|---|---|
| `/boong/submit_order` | service | 요청: `order_id, order_number, flavor, qty` → 응답: `accepted, queue_position, message` |
| `/boong/make_bungeoppang` | action | goal=주문, feedback=`step(batter/filling/baking/packed/ready), detail, piece_index, progress`, result=`success, message` |
| `/boong/orders` | topic(JSON) | 주문 현황: `state(waiting/baking/done/failed), step, queue_position` |
| `/boong/scene` | topic | RViz용 마커 (틀·소스통 3개·봉투·붕어빵) |

웹앱 단계 이름(`batter → filling → baking → packed → ready`)과 feedback `step` 이름을 **똑같이** 맞췄다.

## 5. 실행 순서 (RTX 노트북, `docker/` 폴더)

### A. 로봇 없이 연습 — 에뮬레이터 + RViz (목·금)
```bash
./robot.sh up && ./robot.sh ws    # 이미지 빌드 + 우리 패키지 빌드 (처음 10~20분)
./robot.sh bringup                # 터미널 1: 에뮬레이터 + RViz
./robot.sh boong                  # 터미널 2: 붕봇 노드 + 주문 큐 + rosbridge
./robot.sh order redbean 1 27     # 터미널 3: 주문 → RViz에서 팔이 6동작
./robot.sh orders                 # 주문 현황 보기
```
RViz 처음 1회: `Add → By topic → /boong/scene` 추가.

### B. 실제 로봇 — 토(11/7)·월(11/9)
1. 랜 케이블 연결, 노트북 유선 IP를 `192.168.137.50`으로 고정
2. 티치펜던트: 서보 ON, 원격 제어 허용, 저속
3. `./robot.sh check` → 컨트롤러 IP 찾기 (라벨 IP와 다를 수 있음: 지난번 65 ↔ 64)
4. `.env`: `ROBOT_MODE=real`, `ROBOT_HOST=<찾은 IP>` → `./robot.sh down && ./robot.sh up`
5. `./robot.sh bringup` → RViz 자세가 실제 로봇과 같은지 확인
6. 비상정지 손에 쥐고 `./robot.sh test` (J6 ±10°)
7. 동작 하나씩 좌표 티칭: `./robot.sh step pour_batter` → `add_filling` → `cover_filling` → `flip_mold` → `pick_to_bag`
8. 좌표는 `config/poses.yaml`만 수정 → `./robot.sh ws` → 다시 실행
9. 전체: `./robot.sh boong` + `./robot.sh order redbean 1 27`

## 7. 검토 중인 변경 (아직 코드에 반영 안 됨)

아직 정해지지 않은 아이디어. 팀에서 정하면 코드를 바꾼다.
- 틀 **2칸**: 칸마다 한 번씩 붓기 (수량은 2개 단위)
- 꺼내기: 그리퍼로 집기 대신 **뒤집개/포크로 수평으로 밀어 넣어 뜨기** → 기울어진 받침에 미끄러뜨리기
- 틀 뚜껑: 뒤집은 뒤 열어야 꺼낼 수 있음 (경첩 틀 구매 시 자연스럽게 해결)
- 소품은 만들지 않고 구매: 가정용 붕어빵 팬(알루미늄), 같은 모델 소스통 3개, 스텐 뒤집개, 트레이, 크라프트 봉투 등
