# 붕붕로봇 붕어빵 — 화면 설계 (MVP v0.1)

## 1. 컨셉

> 우리동네 할매·할배가 붕어빵 가게를 열었어요.
> 단팥·슈크림(생크림)·초코, 맛이 많아 고르게 굽기 힘들어서
> 로봇팔 **"붕봇"** 이 대신 구워드려요.

- 톤: 따뜻하고 말랑한 **클레이(3D 점토) 느낌**. 레퍼런스 = 둥근 붕어빵 피규어, 종이봉투, 할매·할배 점토 캐릭터.
- 등장인물
  - **할매** — 주문 안내 + 포장·픽업 담당 (v0.2: 캐릭터를 할매 한 명으로 통일, 3D 클레이)
  - **붕봇** — 로봇팔. 실제로 굽는 주인공. 진행 상태 화면의 주연.
- 말투: 할매 반말-존댓말 섞인 정겨운 톤. 예) "어서 와요~ 뭐 줄까?", "따끈할 때 가져가요!"

## 2. 목표 / 비목표

| 목표 (MVP) | 비목표 (나중에) |
|---|---|
| 임시 로그인 → 주문 → 확인 → 진행상태 → 내역 흐름 완성 | 실제 회원가입/소셜 로그인 |
| 맛 3종 + 수량 선택 | 결제(PG) 연동 |
| 주문 상태를 로봇 진행 단계로 시각화 | 실제 로봇팔 API 연동 (mock 타이머로 대체) |
| 주문 내역 조회 | 사장님(할매·할배) 관리자 화면 |
| 모바일 우선 | 배달, 쿠폰, 포인트 |

## 3. 화면 목록 & 흐름

```
[S1 로그인] ──임시로그인──▶ [S2 메뉴/주문]
                               │ 봉투 담기
                               ▼
                         [S3 주문 확인] ──주문하기──▶ [S4 굽는 중(진행상태)]
                               ▲                              │
                               │ 수정                          │ 완료
                               └──────────                     ▼
[S5 주문 내역] ◀──탭바──▶ [S2]                       "픽업하세요" 상태
     │ 항목 탭
     └────────▶ [S4 주문 상세 = 진행상태 재사용]
```

하단 탭바(로그인 후): **주문하기 | 주문내역**. 우상단 프로필 아이콘 → 로그아웃.

### S1. 로그인 (스플래시 겸용)
- 스플래시 확정(2026-11-06): 시안 3 "붕어빵 공장". 시안 비교 탭과 `?v=` 주소는 제거. 시안 1 밤거리, 시안 2 할아버지는 스플래시에서 빠짐(할아버지 장면은 주문 상태의 픽업 단계에서 계속 사용)
- 눈 내리는 밤, 따뜻한 불빛의 3D 붕어빵 포장마차(빨강·크림 줄무늬 차양, 전구, 붕어빵 틀, 진열장, 빨간 의자) 안에서 할매가 손 흔들기
- 타이틀: 워드마크 SVG "호호붕어빵" (주황 글자 + 크림 외곽선)
- 배경: 짙은 남색 밤하늘(별·눈) + 포장마차 아래 따뜻한 주황 불빛
- 포장마차 장면은 실시간 3D가 아니라 Blender Cycles로 미리 렌더한 투명 PNG(`public/art/login-street.png`, `tools/blender/render_login.py`). 할매 모델은 build_halmae.py를 그대로 불러 사용
- 뒷배경: 눈 덮인 지붕의 집들(창문마다 따뜻한 불빛), 거리 위에 걸린 등불 줄, 가로등. 멀어질수록 밤안개에 녹음
- 장면: 눈 쌓인 겨울 밤거리. 빨간 포장마차 앞에 주황 간판 지붕(아래는 물결 차양, 전구가 줄에 매달림)과 그 간판 얼굴에 붙은 큰 붕어빵, 카운터 위 유리 진열장(할매는 그 안에서 손 흔들기), 붕어빵 틀·쟁반, 메뉴판, 빨간 간이 의자 2개, 눈 더미, 따뜻한 전구 조명, 내리는 눈
- 버튼: **`붕어빵 주문`** (1개, 화면 하단 고정). 탭 → 임시 로그인(랜덤 닉네임) 후 바로 메뉴로 이동
- 별도 스플래시 화면 없음. 로그인한 사용자는 바로 메뉴로
- 상태: 기본 / 입장 실패 시 "입장이 안 됐어요. 다시 눌러 줘요"

### S2. 메뉴 & 주문
- 상단: 노점 카운터 뒤 3D 할매가 목록을 내려다보며 고개 끄덕/갸웃 + 말풍선 "천천히 살펴보고 편히 골라요~" (로봇·붕어빵 없음)
- 맛 카드: 꼬리 한입 베어 문 단면으로 속 색 표시 + 속 이름 태그(팥앙금/커스터드/초코크림)
- 맛 카드 3개 (세로 리스트, 각 카드에 붕어빵 일러스트 색 다르게)
  | 맛 | 컬러 | 가격(가정) |
  |---|---|---|
  | 단팥 | 팥 브라운 | 1,000원 |
  | 슈크림(생크림) | 크림 아이보리 | 1,000원 |
  | 초코 | 초코 다크브라운 | 1,200원 |
  - 각 카드: 이름, 한 줄 설명, 가격, `− 0 +` 스테퍼
- 하단 고정 "종이봉투" 바: 🥮 아이콘이 수량만큼 쌓이는 미니 봉투 + `총 5마리 · 5,200원` + CTA **`봉투 담기`**
- 상태: 빈 봉투(CTA 비활성 대신 탭 시 "한 마리 이상 골라줘요" 토스트) / 최대 수량(맛당 10, 총 20) 도달 시 + 버튼 흔들림 + 안내

### S3. 주문 확인
- 상단: 3D 종이봉투에 주문한 붕어빵이 한 마리씩 퐁퐁 떨어져 쌓임 (꼬리 단면 색으로 맛 구분)
- 영수증: 윗부분 찢긴(지그재그) 모양, 맛별 수량·금액, 점선 아래 합계
- 받는 방법 영역 없음 (매장 픽업 고정)
- 요청사항 (선택, 최대 50자)
- 하단 고정 버튼: `수정하기` / **`주문하기`** — 스크롤과 무관하게 항상 화면 하단
- 주문하기 누르면 봉투 접히고 통통 뛰며 반짝 → S4로 이동
- 실패 시 "주문이 안 들어갔어요. 다시 시도해 줘요"

### S4. 굽는 중 (주문 완료 + 진행 상태)  ← 핵심 화면
- 상단 주문번호 티켓: `No. 027` 큰 숫자 (번호표 느낌)
- 중앙: 붕봇 로봇팔 + 붕어빵 틀 일러스트, 단계별 애니메이션
- 진행 단계 스테퍼 (mock 타이머로 진행):
  1. **주문 접수** — 할매 "주문 받았어요~"
  2. **반죽 붓는 중** — 붕봇이 반죽 붓기
  3. **속 넣는 중** — 맛별 색 속재료
  4. **굽는 중** — 틀이 꽉 닫힌 채 불 위에서 빙글빙글 회전, 불꽃 + 김
  5. **포장 완료** — 할매가 붕어빵을 받아 봉투에 담기
  6. **픽업 대기** — "따끈할 때 가져가요!" + 진동/효과
- 남은 예상 시간 표시
- 하단: `주문 내역 보기`, `또 주문하기`
- 상태: 진행 중 / 완료 / (확장) 취소됨

### S5. 주문 내역
- 리스트 (최신순). 각 행: 날짜·시간, 주문번호, 맛 요약("단팥 2 · 초코 3"), 총액, 상태칩(굽는 중/픽업 대기/픽업 완료)
- 진행 중 주문은 최상단 강조 카드로
- 행 탭 → S4(상세 모드)
- 빈 상태: 빈 종이봉투 일러스트 + "첫 붕어빵을 주문해 봐요" + `주문하러 가기`

## 4. 데이터 모델 (MVP, 로컬)

```ts
type Flavor = 'redbean' | 'cream' | 'choco'

type User = { id: string; nickname: string }

type OrderItem = { flavor: Flavor; qty: number; unitPrice: number }

type OrderStatus =
  | 'received' | 'batter' | 'filling' | 'baking' | 'packed' | 'ready' | 'picked_up'

type Order = {
  id: string
  number: number          // 번호표
  userId: string
  items: OrderItem[]
  memo?: string
  total: number
  status: OrderStatus
  createdAt: string       // ISO
}
```
저장: localStorage (MVP). 이후 서버/로봇 API로 교체 가능하도록 `orderService` 하나로 감쌈.

## 5. 비주얼 방향 (초안)

| 토큰 | 값 | 용도 |
|---|---|---|
| bg | `#FFF6E0` 버터크림 | 배경 |
| primary | `#F5A623` 붕어빵 골드 | CTA, 강조 |
| crust | `#C8782E` 구운 테두리 | 보더, 아이콘 |
| ink | `#5A3A1E` 진갈색 | 본문 텍스트 |
| stamp | `#C8432B` 도장 레드 | 뱃지, 주문번호 |
| paper | `#E9CFA3` 종이봉투 | 카드 배경 |

- 모서리 크게(20–28px), 버튼은 말랑한 pill + 아래쪽 두꺼운 그림자(눌리는 클레이 느낌)
- 폰트: 둥근 한글 서체 (예: Jua / Gowun Dodum 계열) — 확정 전
- 일러스트: 3D 클레이 이미지 생성 or 플랫 SVG 중 택1 (결정 필요)

## 6. 열린 질문 (결정 필요)

1. **플랫폼/스택** — 추천: React + Vite + TS 모바일 웹(PWA). 대안: React Native(Expo), Flutter.
2. **가격** — 위 표는 가정값.
3. **일러스트 방식** — AI 3D 클레이 이미지 vs 직접 그린 SVG.
4. 맛 이름 — "생크림" vs "슈크림" 표기.

## 7. 수용 기준 (MVP)

- [ ] 임시 로그인 후 새로고침해도 로그인 유지, 로그아웃 가능
- [ ] 맛별 수량 선택, 총액 실시간 계산
- [ ] 0마리일 때 주문 진행 불가 + 안내
- [ ] 주문 확인에서 수정/주문 가능
- [ ] 주문 후 진행 단계가 순서대로 진행되어 "픽업 대기"까지 도달
- [ ] 주문 내역에 최신순 표시, 상세 진입 가능, 빈 상태 표시
- [ ] 375px 모바일에서 가로 스크롤 없음
